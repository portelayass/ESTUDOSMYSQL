# Scripts SQL revisados

Esta pasta está reservada para versões revisadas e executáveis dos exemplos.

Para publicar um script aqui, confira:
- se contém apenas SQL válido e comentários SQL (`--` ou `/* ... */`);
- se informa o banco/tabelas necessários;
- se está organizado na ordem correta de execução;
- se foi testado no MySQL;
- se não contém dados pessoais, senhas ou informações confidenciais.

Os exemplos originais estão em `material-original/` e `aulas-organizadas/`.
